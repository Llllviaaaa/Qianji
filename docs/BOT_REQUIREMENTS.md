# 千机（Qianji）Bot 形态产品需求文档（PRD）

> [!NOTE]
> **文档性质**：纯产品需求文档（基于双形态高保真交互原型定稿，不含技术实现与系统架构设计）  
> **核心目标**：在保留千机现有「Agent 工作台」界面与体验完全不变的前提下，新增全天候常驻、具备独立人格与主动服务能力的「Bot 形态」，为分身配备安全隔离的**本地虚拟服务器 / 远端虚拟服务器**，并支持同窗口丝滑切换与跨形态无缝任务接力。

---

## 1. 产品背景与定位

### 1.1 产品背景
千机目前已经具备面向具体工程项目的 **Agent 工作台**，适合用户在明确目标下坐下来编写代码、查看修改对比与操作终端。但在高频日常场景中，用户还需要一个像 **Meta Muse**、**GrokBot** 一样始终在线的 **个人常驻数字分身（Bot 形态）**——它平时安静待在后台替用户盯着关注事项、整理晨报、思考提效点子、接收外部消息，有事随时像微信聊天一样随口交代一句，遇到复杂的专业修改再一键移交到 Agent 工作台处理。

### 1.2 双形态产品定位对比

| 对比维度 | Agent 形态（项目工作台） | Bot 形态（常驻个人分身） |
| :--- | :--- | :--- |
| **核心定位** | 面向具体项目与代码任务的深度操作工作台 | 跨项目、长期记忆用户习惯、全天候陪伴与主动汇报的个人助手 |
| **对话形态** | 按项目划分多个独立任务会话，做完一件事开一个新会话 | **全局唯一、长期延续的「主聊天」时间线** + 随时开启的轻量「旁聊」 |
| **发起方式** | 以用户主动输入任务指令为主 | 用户随手交代 + 周期性后台巡检主动汇报 + 外部消息触发 |
| **工作区保护原则** | 可按用户要求直接在当前工作区操作文件 | **绝不擅自改动用户正在编写的主工作区**；如需准备修改方案，先在独立副本环境中备好草案，等用户进入工作台确认 |
| **敏感操作规则** | 任务进行中实时询问用户 | 后台巡检期间**绝不弹窗打扰**；凡涉及对外发评论、发邮件等敏感动作，统一挂入右侧「批准」栏等用户空闲时一键拍板 |
| **专属运行环境** | 直接操作用户当前选定的本地项目目录 | 拥有分身专属的**隔离虚拟服务器**，支持一键启用 **本地虚拟服务器**（零成本本机隔离）或连接 **远端虚拟服务器**（关机合盖后仍 7×24 小时在线） |

### 1.3 核心产品原则
1. **以「贴心」为第一宗旨（主动理解与服务）**：Bot 形态与 Agent 工作台拥有各自独立的运行逻辑与能力体系——Agent 等你下达指令后再干活，而 Bot 会从日常对话、转发的他人聊天记录与连接的应用动态中主动揣摩你的真实诉求，提前做好准备、制定规划、给出建议并适时提醒。
2. **原有工作台零变动**：切回 `Agent` 形态时，现有首页、侧边栏、对话区和右侧分栏工作台保持 100% 原样，不改变老用户任何操作习惯。
3. **同窗丝滑切换**：右上角常驻 `Agent | Bot` 切换开关，来回切换时界面连贯伸缩过渡，不闪屏、按钮不跳位、草稿与浏览位置不丢失。
4. **分级触达与专注零打扰**：重要急件与临近会议通过桌面通知和主聊天直给结论，日常动态按节奏汇总早晚简报；在视频会议、深度专注或免打扰时段保持静默，不弹出琐碎通知刷屏。
5. **数据完全归属用户**：分身的人格设定、长期记忆、聊天记录与连接凭据全部保存在用户本机或用户自己配置的服务器上，不强制绑定任何第三方账号。

## 1A. 贴心主动能力：日常应用连接与主动理解体系

> [!NOTE]
> 以下为已确认定稿的贴心分身主动服务需求，聚焦「读懂你」与「连上你日常需要的应用」。

### 1A.1 主动理解话外之音与自我学习
- **从对话与沟通片段找准真实诉求**：面对用户的吐槽、纠结或转发过来的同事/客户沟通片段，分身主动剖析隐藏卡点、关键截止时间与对方真正期望的答复，不再只停留在字面客套回应。
- **会后与聊后自动顺手推进**：聊完涉及长期跟进的事项时，在对话结束后主动梳理归纳：若发现新的偏好习惯则透明写入长期记忆与「最近习得的偏好」；若识别出跨天待办则主动纳入「目标」或关联「常驻空间」。

### 1A.2 四大日常应用与工作状态连接
1. **邮箱贴身管家**：接入个人及工作常用邮箱（支持 QQ 邮箱、163 邮箱、Gmail、Outlook 及自定义邮件服务器），定时静默收信并识别核心来信、待回复请求与截止期限；不仅摘要提醒，还结合过往背景在「批准」栏提前拟好可直接发送的回信草稿。
2. **日历与会议参谋**：接入网络日历订阅与本地日程文件，每天梳理全天行程；发现时间冲突主动预警并给出现成调整方案；在会议临近时提前提醒，并把关联的历史沟通与资料汇总手边。
3. **电脑进程与工作状态感知**：柔和感知当前正在使用的软件与活跃窗口（支持自定义盯守耗时任务或构建程序）：开会或高度专注时自动放轻提醒避免打扰；盯守的任务结束或深夜仍在工作时，第一时间给出结果通知或温和关怀。
4. **会议纪要目录与外部消息渠道**：持续留意指定会议纪要文件夹中的新记录，并接入飞书、Telegram 等常用外部沟通渠道；汇总外部来信与会后行动项，自动转化为规划建议与待确认跟进事项。

### 1A.3 分级贴心触达与「永远带着半成品来汇报」
- **分级触达**：紧急事项（临近会议、重要加急邮件、盯守任务结束）触发系统桌面通知并在主聊天主动发消息给出建议；日常事项温和收集至「动态」简报与早晚小结；巡检一切平稳时完全安静。
- **自带建议与草稿**：每条提醒都尽量把「谁、要什么、建议几点处理、拟好的回复草稿」准备齐全，让用户直接做选择题而非填空题。
- **对内放手准备、对外必经确认**：所有阅读收信、理日程、写总结与拟草稿都在安全边界内主动完成；所有真实向外发出邮件、外部消息或高影响操作一律放入右侧 **「批准」** 栏，展示完整待发收件人与正文，由用户亲自点击「批准」后才真正发出。

## 2. 全局布局、视觉与切换交互需求

### 2.1 Bot 形态整体三栏布局
Bot 形态采用全窗口通高三栏结构，所有顶部操作按钮对齐在**同一条顶部水平线**上，视觉清爽无多余顶栏嵌套：

1. **左侧导航侧坞（窄栏常驻）**
   - 顶部：千机品牌图标（点击直接回到主聊天）。
   - 中部：垂直居中排列 7 个核心功能入口（`聊天`、`搜索`、`动态`、`点子`、`目标`、`资源库`、`创建空间`），采用圆形胶囊选中态。
   - 底部：仅保留一个 `=` 更多菜单入口（不放置多余下载按钮，也不展示传统桌面菜单文字）。
2. **中间主内容区（自适应宽度）**
   - 根据当前选中的左侧模块，展示聊天流、动态流、点子列表、目标看板、带二级分类栏的资源库，或左右分屏的创建空间页面。
3. **右侧常驻陪伴面板（可收起）**
   - 顶部右侧固定放置全局 `[ Agent | Bot ]` 切换胶囊与窗口最小化、最大化、关闭按钮（面板内不再重复出现第二个 `×` 关闭按钮）。
   - 上半部展示分身 3D 虚拟形象、分身名称与在线/服务器节点状态；下半部通过四分栏胶囊切换 `动态`、`批准`、`身份`、`邮箱` 四个面板。
   - 当用户在聊天页点击右上 `[◨]` 收起陪伴面板，或进入 `资源库` / `创建空间` 全宽页面时，主内容区自动平滑铺满右侧空间，且顶部按钮自动预留间距，绝不与右上角 `[ Agent | Bot ]` 重叠。

### 2.2 `Agent ⇄ Bot` 切换动效与状态保持需求
- **固定锚点与滑块反馈**：右上角 `[ Agent | Bot ]` 胶囊在两种形态下位于完全相同的屏幕位置，点击时内部白色滑块平滑左右滑动，左侧属于 Agent 工作台的快捷小图标同步平滑收起或展开。
- **窗口骨架连贯过渡**：
  - 切入 `Bot` 时：Agent 顶部传统菜单栏柔和向上收起；左侧宽侧边栏平滑收窄为窄侧坞，左上千机图标连贯滑入侧坞顶部中央；中间带圆角边距的画布自然铺满全窗；内容区与右侧陪伴面板平滑推入。
  - 切回 `Agent` 时：执行完全对称的反向过渡动画。
- **状态完整保留**：来回切换双形态时，两边各自打开的页面、列表滚动条位置以及输入框里尚未发送的文字草稿均完整保留。

### 2.3 主题、色彩与陪伴形象要求
- **双主题实时同步**：完整支持浅色模式与深色模式一键同步切换，两边色彩风格统一。
- **无生硬边框视觉**：页面内的卡片（点子、目标、空间、批准、身份、收件箱）统一采用柔和圆角色块呈现，避免满屏生硬的细黑框线条；主操作按钮统一采用高对比单色圆角胶囊样式。
- **克制温润的陪伴形象**：默认采用中性素白色调的 3D 毛毡伙伴形象，内置多款风格统一的预设形象供一键切换，并支持自定义上传头像。

### 2.4 全局快捷键需求

| 快捷键 | 功能说明 |
| :--- | :--- |
| `Ctrl + Shift + M` | 在 `Agent` 工作台与 `Bot` 形态之间丝滑往返切换 |
| `Ctrl + J` | 快速切回 Bot「主聊天」页面并聚焦底部输入框 |
| `Ctrl + K` | 打开全局搜索弹窗 |
| `Ctrl + ,` | 打开设置中心弹窗 |
| `Esc` | 关闭当前打开的弹窗、搜索框或左下角更多菜单 |

## 3. 左侧侧坞七大功能模块需求

### 3.1 聊天（主聊天 + 旁聊抽屉 + 通话）
1. **常驻主聊天时间线**
   - 作为用户与分身之间唯一、不断档的长期对话窗口，按日期与时间段自动插入轻量时间分隔（如 `11月18日 8:30`、`今天 15:20`）。
   - 支持展示三类核心消息：
     - **用户消息气泡**与**分身常规回复气泡**（连续多段发言自动贴合圆角）；
     - **主动晨报/巡检汇总气泡**（分身按约定时间汇总项目状态、测试结果或待办提醒）；
     - **内嵌任务提醒挂件气泡**：在聊天气泡内以细分割线嵌入结构化任务卡（含任务图标、任务名称、任务类型标签、异常或进展摘要，以及全宽胶囊按钮如 **`在 Agent 工作台中打开`**）。
2. **单条消息悬停轻操作**
   - 鼠标移入任一分身消息时，气泡旁浮现三个轻量操作按钮：**表情回应**、**引用回复此消息**、**更多操作**（复制全文、以此消息开启独立旁聊等）。
3. **底部悬浮输入舱**
   - 底部居中悬浮毛玻璃圆角胶囊输入框，左侧提供 `+` 按钮用于添加本地文件或目录参考，中间为文本输入区（回车直接发送），右侧提供语音输入按钮。
4. **旁聊抽屉（Side Chats）**
   - 点击主画布左上角 `[≡ 聊天]` 胶囊按钮，从侧坞右侧平滑滑出旁聊列表抽屉（再次点击或点抽屉内 `×` 收起）。
   - 抽屉内分为 **「主要聊天（主聊天）」** 与 **「旁聊」** 两个分组，右上提供 `+` 按钮一键开启新旁聊。
   - 旁聊用于探讨临时问题、比价测算或分支小实验，避免临时问答刷乱主聊天上下文；切换到某个旁聊时，左上角胶囊文字同步显示该旁聊标题。
5. **顶部右侧辅助按钮**
   - `[📞 通话]`：启动与分身的实时语音对话模式。
   - `[◨]`：一键收起或展开右侧常驻陪伴面板。

### 3.2 搜索（全局检索弹窗）
- 点击侧坞放大镜图标或按 `Ctrl + K` 呼出居中搜索弹窗。
- 未输入内容时，默认展示 **「最近访问」** 的聊天、旁聊与空间记录。
- 输入关键词时，实时检索主聊天、全部旁聊、常驻空间、归档文档与记忆档案，列表展示匹配标题、时间与正文摘要片段；点击任意结果立即关闭弹窗并跳转定位至目标内容。

### 3.3 动态（主动情报流）
- 以清爽的单栏文章流形式，汇总分身在后台持续关注并整理出的重点动态（例如关注仓库新增的重要测试与分支变化、周期性资源消耗/效率统计、行业或项目关键进展等）。
- 每条动态包含标题、相对时间、核心要点摘要，以及底部行动胶囊按钮（如 `讨论`、`开始吧`）；点击按钮即可带着该条动态背景进入主聊天继续深入交流。

### 3.4 点子（主动建议库）
- 展示分身根据用户近期工作内容、项目健康状况与日常习惯主动构思的**可落地好点子**。
- 页面顶部展示简短亲切的引导说明，下方按场景分组（如默认精选、`开发与工作区`、`效率提升` 等）；每条点子包含专属小图标、一句话提案标题与具体价值描述。
- 用户点击任意一条点子，自动回到主聊天由分身立即着手执行或确认细节。

### 3.5 目标（长期事项追踪）
- **追踪中目标**：卡片式展示用户交给分身长期盯办的目标（含完成状态图标、目标标题与当前最新跟进进展说明），点击可查看目标详情或切入关联工作台。
- **创建目标**：提供常见目标领域分类入口（`职业与研发`、`效率提升`、`金融`、`健康`、`人际关系`、`兴趣`、`其他`），点击任一分类 `+` 号后自动进入聊天，由分身通过对话帮用户明确目标指标与定期检查频率。

### 3.6 资源库（空间 / 文档 / 影音 / 系统文件）
进入资源库时自动收起右侧陪伴面板，采用 **「左侧二级分类栏 + 右侧内容画布」** 布局：
1. **文件 → 空间**：网格卡片展示所有长期保留的专题看板（展示常驻标签、最近更新时间、空间名称、简介、核心状态指标胶囊及 `打开看板` 链接）；右上角提供 `选择`（批量管理）与 `+ 创建空间` 主按钮。
2. **文件 → 文档**：集中归档分身生成的各类诊断报告、周期总结与整理文档，显示文档名、更新时间与大小，支持一键打开查阅。
3. **影音内容 → 图片 / 视频 / 播客**：按类型归档对话中生成或收藏的图片、视频与音频播客，暂无内容时展示清晰的空状态提示。
4. **底部固定入口 → 系统文件**：展示分身最核心的两份底层档案卡片——**`SOUL.md`**（核心性格、沟通风格与安全底线）与 **`MEMORY.md`**（长期记忆的工作习惯与偏好），标注谨慎访问提示与最近修改日期，点击可打开编辑弹窗审阅或修改。

### 3.7 创建空间（对话式分屏搭建）
- 采用 **「左对话 + 右预览画布」** 左右分屏视图，底部输入框自动带入引导前缀（`我想创建一个空间，关于 `）。
- 用户只需用日常语言描述想持续追踪的主题（例如某个重点任务的进展脉冲、某项开支或效率看板），右侧即可生成对应的可视化空间卡片并保存到「资源库 → 空间」中持续自动更新。

### 3.8 左下 `=` 更多菜单
- 点击侧坞底部 `=` 按钮弹出轻量浮层菜单，包含三项入口：
  1. **键盘快捷键**：弹出快捷键速查卡片；
  2. **报告问题**：打开问题反馈入口；
  3. **设置（`Ctrl + ,`）**：打开双栏设置中心弹窗。

## 4. 右侧常驻陪伴面板需求

### 4.1 陪伴形象、名称与虚拟服务器状态区
- 居中展示圆形 3D 分身形象，右下角带编辑小按钮，点击可快速轮换或选择虚拟形象。
- 形象下方显示分身名称（默认“千机”），以及当前挂载的**虚拟服务器状态胶囊**（例如 `● 运行中 · 本地虚拟服务器` 或 `● 云端守护 · 远端虚拟服务器`）；点击该状态胶囊可直接弹出虚拟服务器状态速览（CPU / 内存 / 磁盘占用、实时画面入口）或进入「虚拟服务器」设置页。

### 4.2 四分栏胶囊切换器
采用带平滑滑动白底块的四图标胶囊切换以下四个子面板：

1. **动态（后台行动记录）**
   - **预定任务折叠区**：顶部展示当前开启的周期任务数量（如 `1 项预定任务` → `Heartbeat 每 30 分钟`），支持点击直接暂停/启用单条定时任务，或点击 `查看所有预定任务` 统一管理。
   - **按日分组历史流**：按 `昨天`、`MM月DD日` 倒序记录分身在后台自动完成的每一项具体工作、简短说明与发生时间，点击任一记录可追溯对应上下文或进入工作台核对。
2. **批准（敏感操作待审箱）**
   - **待确认卡片**：当后台任务需要执行对外评论、发消息/邮件、修改受保护内容等敏感动作时，生成待批准卡片，清晰写明操作标题、具体动作类型与影响说明（例如“只发诊断摘要评论，不改动代码分支”），提供醒目的 **`批准`** 与 **`拒绝`** 双按钮。
   - **最近审核记录**：下方保留近期已批准、已拒绝以及符合安全白名单自动放行的历史记录，做到后台行为全程透明。
3. **身份（分身设定与记忆管理）**
   - **名称名片卡**：展示分身当前名称与定位简介，点击 `编辑` 可直接在行内修改名称并即时全局生效。
   - **`SOUL` 与 `记忆` 双卡片**：并列展示两张圆角方卡，点击弹出专属文本编辑窗口，方便用户直接查看、修改分身的人格原则或手动修正某条长期记忆。
   - **最近习得的偏好**：列表简明展示分身近期从合作中总结出的用户习惯要点（如偏好的代码安全习惯、静默免打扰时段等）。
4. **邮箱 / 收件箱（外部消息聚合）**
   - 未启用时展示清晰的空状态说明与 `创建邮箱 / 绑定收件源` 按钮。
   - 启用后展示专属接收地址（支持一键复制）及收到的外部通知、告警邮件或转发消息列表；点击任意一封消息，自动转入主聊天让分身帮用户摘要、回复或跟进处理。

## 5. 分身专属虚拟服务器需求（本地虚拟服务器 + 远端虚拟服务器）

### 5.1 产品设计诉求
参考 Muse AI 与 GrokBot 为每个 Bot 配备一台专属虚拟电脑的产品形态，千机 Bot 同样拥有属于自己的**独立虚拟服务器环境**（独立的文件空间、软件环境与专属浏览器）。分身的所有后台巡检、环境搭建、脚本执行、文件下载与网页浏览均在虚拟服务器内完成，既避免弄乱或破坏用户的个人电脑系统，又能同时满足「零成本本地隔离运行」与「关机合盖后 7×24 小时全天候在线」两类核心需求。

### 5.2 本地虚拟服务器需求（Local Virtual Server）
面向不想购买外部服务器、希望在本机开箱即用的用户：
1. **一键创建与开箱即用**：首次启用时引导一键初始化分身专属的本地虚拟服务器，无需用户手动配置复杂虚拟化环境。
2. **与个人电脑严格隔离 + 受控目录共享**：
   - 默认情况下，本地虚拟服务器拥有独立磁盘空间，无法随意读写用户个人桌面、文档或系统目录，分身在里面安装软件或跑实验脚本完全不影响宿主机。
   - 用户可在设置中显式添加允许共享给本地虚拟服务器的项目文件夹，并指定访问权限（如「仅只读巡检」或「允许在独立副本中修改」）。
3. **资源限额与空闲智能休眠**：
   - 支持配置本地虚拟服务器的最高资源上限（处理器核数、最大内存占用、虚拟磁盘容量上限），确保不拖慢用户日常办公与本地工作台。
   - 支持「空闲自动休眠」：当分身没有执行任务时自动挂起释放内存；当用户发来新消息或定时巡检时间到达时，数秒内自动唤醒恢复工作。
   - 支持「关闭窗口驻留托盘」：关掉主界面后，本地虚拟服务器可在系统托盘后台继续静默值守。

### 5.3 远端虚拟服务器需求（Remote Virtual Server）
面向希望笔记本合盖休眠、下班关机后分身依然 7×24 小时在线工作的用户：
1. **远端虚拟服务器连接与一键初始化**：
   - 支持添加和管理一台或多台用户自己的远端虚拟服务器（个人云主机、家庭常开迷你主机/NAS、团队开发机等），填写服务器地址、端口与登录凭据。
   - 提供 **「测试连接」** 与 **「一键初始化/更新远端虚拟服务器环境」** 能力，自动把远端主机配置为分身可用的常驻虚拟服务器，降低配置门槛。
2. **7×24 小时离线托管与开盖自动同步**：
   - 当用户电脑休眠或关机断网期间，分身在远端虚拟服务器中照常执行周期巡检、通宵长任务、网页信息采集与收件箱收信。
   - 当用户重新打开电脑连接上远端虚拟服务器后，离线期间产生的所有聊天汇报、动态、点子、待批准事项与产出文件自动完整同步回界面，不丢任何进展。
3. **断连提示与无缝切换**：
   - 若远端虚拟服务器网络波动或离线，陪伴面板顶部状态胶囊清晰提示重连状态，并支持随时切换回本地虚拟服务器应急使用，两边共享统一的分身身份（`SOUL`）与核心记忆设置。

### 5.4 虚拟服务器通用管控体验需求（本地与远端共通）
1. **运行监控与生命周期操作**：在设置中心及陪伴栏状态浮层中，直观展示当前虚拟服务器的运行状态（运行中 / 休眠中 / 连接中 / 已停止）、CPU / 内存 / 磁盘剩余空间与连续运行时长，提供一键 **启动、休眠、重启** 按钮。
2. **实时画面查看与人工接管（Live View & Takeover）**：
   - 用户可随时打开虚拟服务器的实时工作画面，直观看到分身当前打开的网页或执行进度。
   - 当分身在虚拟服务器浏览器中遇到登录扫码、验证码或需要人工确认的步骤时，主动在聊天与状态栏提醒用户；用户点开实时画面即可直接手动点击完成验证，随后交还分身继续执行，全程无需向分身发送明文账号密码。
3. **环境快照与一键重置**：
   - 支持为虚拟服务器创建干净快照，或提供 **「一键重置虚拟服务器环境」** 按钮——当虚拟服务器内安装的测试环境混乱或磁盘占满时，可一键恢复至初始纯净状态，且默认完整保留分身的 `SOUL` 人格设定、聊天记录与长期记忆不丢失。
4. **虚拟服务器产出物自动归档**：分身在本地或远端虚拟服务器内生成的报告文档、图表空间、图片与音视频，自动同步展示在「资源库」中，支持一键下载保存到用户电脑本地目录。

## 6. Bot 与 Agent 工作台双向协同需求

1. **从 Bot 一键切入工作台核对（正向接力）**
   - 当分身在后台巡检发现项目异常（如构建失败、测试报错）并预先在安全隔离副本中准备好修改草案后，会在主聊天发送带 **`在 Agent 工作台中打开`** 按钮的任务卡片。
   - 用户点击该按钮后，窗口丝滑切换至 `Agent` 分栏工作台，顶部轻提示已带入对应任务上下文，右侧直接展开准备好的代码修改对比与对应文件，且**完全不影响用户原本正在编辑的主分支内容**（即使该草案由远程服务器上的分身生成，点击后也能自动同步到本地安全副本中供用户审阅）。
2. **从工作台完成并回传 Bot（反向闭环）**
   - 凡是由 Bot 接力打开的工作台任务，顶部标题栏右侧提供醒目的 **`← 完成并回传 Bot`** 按钮。
   - 用户审阅、调整或验证通过后点击该按钮，窗口丝滑切回 `Bot` 主聊天，自动追加一条完成回传汇总消息，并同步记入右侧「动态」历史，形成从“分身发现问题 → 准备草案 → 用户在工作台拍板 → 结果归档回分身”的完整闭环。

## 7. 设置中心模块清单

在 Bot 左下角 `=` → `设置`（或快捷键 `Ctrl + ,`）打开的双栏设置弹窗中，包含以下九个配置分组，且通用项与千机全局设置保持实时同步：

| 设置分组 | 核心配置内容 |
| :--- | :--- |
| **通用** | 浅色 / 深色外观主题切换、**分身主力对话模型与轻巡检模型独立选择**、巡检频率与免打扰时段设置、关闭窗口时驻留系统托盘开关 |
| **虚拟服务器** | **本地虚拟服务器**（一键创建、CPU/内存/磁盘限额、受控共享目录、空闲休眠）与 **远端虚拟服务器**（连接配置、测试与一键初始化）切换；启动/休眠/重启、实时画面接管、快照与一键重置环境 |
| **浏览器** | 虚拟服务器内浏览任务是否默认静默运行、遇到登录/敏感点击时的人工接管提醒与批准开关 |
| **连接器** | 配置并一键连接 **邮箱管家（收信/回信准备）**、**日历与会议（日程规划/会前提醒）**、**本机进程感知与长任务盯守**、**会议纪要目录与飞书 / Telegram 消息渠道**，支持独立开关与即时同步测试 |
| **安全存储** | 管理分身代管的服务访问凭据与密钥（仅保存加密引用，支持随时撤销删除） |
| **权限** | 配置后台巡检允许自动放行的安全操作范围，以及必须进入「批准」栏人工确认的操作规则 |
| **消息渠道** | 配置专属收件箱及外部即时通讯/Webhook 通知绑定，支持在外用手机接收高优提醒 |
| **数据控制** | 导出或清理聊天历史、清理后台临时缓存目录、重置记忆档案 |
| **声音和虚拟形象** | 切换预设 3D 陪伴形象、上传自定义形象头像、选择实时通话语音音色 |

## 8. 产品验收标准（Acceptance Criteria）

1. **双形态无损切换**：在任意页面点击右上角 `Agent | Bot` 或按 `Ctrl + Shift + M`，切换过程连贯顺滑无闪屏、右上角开关位置不跳动；切回 `Agent` 时与原有千机界面 100% 一致。
2. **布局干净一致**：Bot 页面左上角无传统菜单文字栏、左下角无多余下载按钮、右上角无上下重叠的两个关闭按钮；收起右侧陪伴面板或进入资源库时，顶部所有按钮互不遮挡。
3. **七大侧坞模块与四分栏完备可用**：左侧 `聊天（含旁聊抽屉）`、`搜索`、`动态`、`点子`、`目标`、`资源库（空间/文档/影音/系统文件）`、`创建空间` 以及右侧 `动态`、`批准`、`身份（SOUL 与记忆编辑）`、`邮箱` 全部交互闭环可用，浅色与深色主题视觉和谐统一。
4. **安全与免打扰达标**：后台巡检无异常时不向主聊天发骚扰消息；后台绝不直接修改用户原工作区主分支；涉及外部写操作时 100% 进入右侧「批准」栏等待用户点击批准或拒绝，绝不擅自弹窗或越权执行。
5. **本地与远端虚拟服务器闭环可用**：本地虚拟服务器与个人电脑目录严格隔离，支持限额、空闲休眠、实时画面人工接管及保留记忆的一键重置；远端虚拟服务器在电脑合盖断连后仍持续运行，重连后离线消息、产出文件与待批准记录自动完整补齐。
6. **跨形态接力闭环**：无论修改草案由本地虚拟服务器还是远端虚拟服务器生成，点击聊天任务卡中的「在 Agent 工作台中打开」均可携带上下文平滑进入本机工作台查看修改对比，点击「完成并回传 Bot」可平滑切回并落盘汇总记录。
